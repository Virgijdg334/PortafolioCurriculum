
# 🚀 Portafolio & Currículum Vitae

Este repositorio contiene el código fuente de mi portafolio personal y currículum online, una plataforma diseñada para mostrar mi trayectoria profesional, proyectos y habilidades técnicas como desarrollador.

**Link del proyecto:** [https://virgijdg334.github.io/PortafolioCurriculum/](https://virgijdg334.github.io/PortafolioCurriculum/)

## 📋 Descripción

El sitio funciona como una carta de presentación interactiva. Se enfoca en la claridad visual y la facilidad de navegación para que reclutadores y colaboradores puedan conocer mi perfil de un vistazo. Incluye secciones detalladas sobre mi formación académica, experiencia y un showcase de proyectos destacados.

## 🛠️ Tecnologías Utilizadas

Para el desarrollo de esta web se han empleado las tecnologías fundamentales del desarrollo frontend:

* **HTML5:** Estructura semántica del contenido.
* **CSS3:** Diseño visual, tipografías y estilos personalizados.
* **JavaScript (Vanilla):** Interactividad y lógica de la interfaz.
* **GitHub Pages:** Hosting y despliegue automático.

## ✨ Características Principales

* **Diseño Responsive:** Adaptado para una visualización óptima en ordenadores, tablets y dispositivos móviles.
* **Sección de Formación:** Detalle de mis estudios (especialmente enfocado a DAM).
* **Proyectos:** Galería con enlaces y descripciones de mis desarrollos más recientes.
* **Contacto Directo:** Enlaces a redes profesionales (LinkedIn, GitHub) y correo electrónico.
* **Navegación Fluida:** Menú intuitivo con scroll suave entre las secciones de la página.
